# AI Plant Disease Detection System

# Project Overview

AI Plant Disease Detection System is a deep learning-based web application that identifies plant diseases from leaf images. The system helps farmers, researchers, and agriculture enthusiasts detect crop diseases quickly and accurately using computer vision and artificial intelligence.

The application allows users to upload leaf images, receive disease predictions, view confidence scores, and maintain prediction history through a user-friendly dashboard.

# Features

User Registration & Login System
Secure User Authentication
Upload Plant Leaf Images
AI-Based Disease Prediction
Top-5 Disease Predictions with Confidence Scores
Prediction History Tracking
Interactive Dashboard
Modern Responsive UI with Streamlit

# Deep Learning Model

* Model Architecture: EfficientNet
* Framework: TensorFlow / Keras
* Input Image Size: 224 × 224
* Multi-Class Plant Disease Classification
* Real-Time Prediction System

#  Workflow

1. User registers and logs into the system.
2. User uploads a plant leaf image.
3. Image is preprocessed and resized.
4. EfficientNet model analyzes the image.
5. System predicts the disease category.
6. Confidence scores are displayed.
7. Prediction history is stored in the database.
